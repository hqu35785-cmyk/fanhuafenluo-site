# 新站快捷卡片发布工具

一个只在本机运行的小工具。双击桌面快捷方式，选分区、拖入 PNG、定稿简介，然后点一次发布。没有 AI API Key、付费接口或额外账号配置；AI 写简介这一步由你把素材复制到自己使用的 AI 中完成。

## 开始使用

需要 Windows、Node.js 22+、Git，以及已经登录的 GitHub Git 凭据。先在仓库目录运行一次：

```powershell
npm ci
npm run publisher:install
```

后台 Git 检查始终以非交互方式运行，不会暗中弹出登录窗口或等待输入；它会从当前 PATH 或 Git for Windows 的标准安装位置定位 `git.exe`。若 Git、网络或已有 GitHub 凭据不可用，工具会保持发布禁用并给出“重新检查”提示，不会尝试自动登录或推送。

安装器会在当前用户的实际桌面创建三个快捷方式：

- **新站快捷发布卡片**：打开后选择分区。
- **新站发布到繁花·纷落**：预选“繁花·纷落”。
- **新站发布到公开**：预选“公开”。

双击任意一个，或把一张 PNG 拖到快捷方式上。也可以运行 `npm run publisher`。启动器会复用已经运行的本地服务，打开默认浏览器，不显示常驻终端窗口。同名但指向其他程序的已有快捷方式不会被覆盖。移动整个仓库后，需要重新安装快捷方式；若提示目标冲突，先人工处理旧快捷方式。

## 日常流程

1. 选择“繁花·纷落”或“公开”，拖入含 `chara` 元数据的 PNG。也支持点击选择文件。最大 64 MiB，一次一张。
2. 工具自动读出角色名、真实作者、标签，生成 WebP 预览。原始 PNG 不会被改写。
3. 点击“复制素材 + 简介提示词”，发给你使用的 AI；不便复制时可下载为文本。内容包含原始人物资料、开场白、世界书和预设等已支持的字段及写作要求。
4. 审核 AI 结果，粘贴或手写 120–180 个非空白字符的独立简介。**新导入卡片的简介始终为空，不会把 `description` 填进去，也不会静默生成或上传 AI 内容。**
5. 核对分区、图片、设定、发布权限及简介。可先“校验并保存草稿”，也可直接“发布到…”；后者会执行同样的简介校验。
6. 等待发布进度完成。只有核对线上构建提交与卡片目录后，才显示成功。若“尚待上线确认”或“推送结果待确认”，点击“重新检查上线状态”，该按钮只检查，不会再次推送。

简介框在当前浏览器标签页的会话中自动保留；“校验并保存草稿”把定稿保存到本机服务。下次打开工具，可用“继续本地草稿”下拉框找回最近导入的卡片及已保存的简介。导入另一张 PNG 会清空简介，防止把上一篇简介带入新卡。草稿不是已经发布的卡片。

## 当前发布闸门

工具只允许向新仓库 `hqu35785-cmyk/fanhuafenluo-site` 的 `main` 做普通快进推送，上线检查固定使用 `https://hqu35785-cmyk.github.io/fanhuafenluo-site/`。它不会将当前本地整理分支整体推上去，也不会修改旧 `hqu35785-cmyk/fanhuafenluo` 或 `fanhuafenluo-pages` 仓库。

新站远端 `main` 必须拥有可发布结构：`src/data/catalog.json`（schemaVersion 1，两个指定分区）、卡片导入脚本、锁定依赖、验证/构建脚本和 Pages 工作流。结构不完整时会显示“新站远端尚未具备发布所需结构”，发布按钮禁用，但导入、复制素材、写简介和保存草稿都可使用。

工具就绪检查只核对远端版本具备必要结构，不替代发布者对网站内容、Pages 设置和部署权限的人工验收；结构修复后可在工具中点“重新检查”。

## 发布时发生什么

工具从远端最新 `main` 创建隔离的临时克隆；安装锁定依赖；在目标分区的置顶卡之后加入一张卡；生成预览与详情；运行测试、资源校验、详情一致性校验、站点构建和构建产物校验；精确暂存本次产生的文件；创建一次卡片发布提交；再次核对远端未变化，普通推送到 `main`；最后等待网站上线。

当前工作区里未提交的其他修改不参与发布。不会强推、自动变基或覆盖远端变化。执行失败时草稿保留；推送请求中断时先检查该提交是否已在远端，不能确认就停止重推。内容完全相同的 PNG 会被拒绝重复加入目录。

原始图像写入 `assets/cards/<SHA256前20位>.png`，预览写入 `assets/previews/cards/<相同文件名>.webp`。源资料、定稿简介及原始 PNG 完整性有独立哈希校验。新卡默认启用敏感卡面遮罩；没有源创建日期时不编造创建日期。

## 隐私与本地数据

服务仅监听 `127.0.0.1` 随机端口，API 使用随机访问令牌并检查 Host、Origin 等来源信息。令牌只通过浏览器地址片段传递，页面读取后从地址栏移除，不写入网站构建、Git 提交或公开日志。

草稿 PNG、预览、定稿简介、发布记录和运行信息保存在当前用户专属的 `%LOCALAPPDATA%\FanHuaSitePublisher`，不放进站点仓库，也不复用旧发布工具的运行目录。日志只记录技术事件，不记录令牌或原始设定。它们仍是本机明文文件，应视为个人资料保管，不要上传或分享这个目录。关闭浏览器不会关闭本地服务，后续启动会复用它；重启电脑后再次点击快捷方式即可。

工具不会自动把素材发给 AI。只有你主动复制/下载，或点击发布时，相关资料才离开该本地处理流程。`tools/card-publisher` 不会进入 `_site`，不会作为公开网页发布。

快捷方式启动失败会弹出简短提示；可先查看 `launcher.log` 与 `server.log`。锁状态损坏、恢复锁残留或已有其他仓库服务占用同一状态目录时，工具会停止自动处理。维护者应先核对相关进程、保留草稿，再处理特定锁文件，不要清空整个本地数据目录。更新工具代码后，需要重启本地服务；重启电脑后重新点击快捷方式也是可行的方式。

`blocked-card-hashes.json` 保存此前安全清理确认排除的 PNG 的 SHA-256，仅含不可读的指纹，不包含原始内容。它在本地导入、发布及命令行导入中拦截这些文件。哈希拦截不是对任意新内容的自动审查，发布者仍需审核，不能上传涉及未成年人的色情内容。

## 检查与维护

```powershell
npm test
npm run test:publisher
npm run build:pages
npm run test:ui -- --project=chromium
```

浏览器测试使用本地合成的中性角色卡与模拟接口。Git 发布测试使用一次性本地 bare 仓库和模拟部署检查，不向真实 GitHub 推送测试卡。

核心文件：

| 文件 | 作用 |
| --- | --- |
| `launcher.mjs`、`launch.vbs` | 隐藏启动、复用本机服务、快捷方式拖入 PNG |
| `install-shortcuts.ps1` | 创建当前用户桌面的三个快捷方式 |
| `server.mjs` | 本地 API、草稿、访问控制与静态界面 |
| `git-publisher.mjs` | 远端闸门、隔离发布、幂等和上线检查 |
| `public/` | 中文操作界面，无外部前端依赖 |
| `../../scripts/lib/card-import.mjs` | PNG 解析、预览、目录导入与失败回滚 |
| `../../scripts/add-role-card.mjs` | 同一导入逻辑的命令行入口，仅修改指定本地仓库 |

命令行导入需要 UTF-8 简介文件，不会自行提交或推送：

```powershell
node scripts/add-role-card.mjs --section public --card "C:\Cards\示例.png" --intro-file "C:\Cards\简介.txt" --result-file "C:\Cards\导入结果.json"
```

结果文件应放在仓库外的专用路径，不要指向已有资料。一般用户直接使用快捷方式即可。
